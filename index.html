The Framework

Context · Task · Format

Every professional prompt has three layers. Click each to understand what it controls — and what breaks when it's missing.

🏷️ Context
🎯 Task
📐 Format
CONTEXT — Who is the agent? What does it know? Context is the role, expertise, and situational knowledge you give the agent before it does anything. It answers: who is this agent, what does it already know, what constraints apply, and what perspective should it reason from.

Without context: The agent has no persona — it defaults to a generic assistant with no domain authority.
With strong context: "You are a senior clinical documentation specialist at a HIPAA-compliant telehealth platform with 8 years of experience reviewing physician intake forms." — the agent now reasons from that position.
The Confusion Tax
Weak Prompt

"Summarize the customer feedback and tell me what to do about it."

No role, no output type, no constraints. Every run produces a different result.

Strong CTF Prompt

[C] "You are a CX analyst at a B2B SaaS company…
[T] Analyze the 10 reviews below and identify the top 3 themes…
[F] Return a JSON array with theme, frequency, and urgency."

Role defined. Goal precise. Output deterministic. Works every time.
